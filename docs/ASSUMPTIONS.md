# Assumptions
1. All market and produce data is sample data created for this project to demonstrate the site. Market names are based on real Lagos areas, but details such as hours and produce lists are illustrative.
2. The site presents eight sample markets. More can be added by adding records to markets.json without changing any code.
3. The chatbot answers only questions covered in its JSON dataset. It matches keywords and phrases and does not learn or connect to any outside service.
4. Bookmarks and notes are kept in the browser session only and disappear when the tab is closed, as the brief requires session only notes and no server storage.
5. The login and sign up buttons are decorative. The brief asks for non functional buttons for design continuity and the site has no user accounts.
6. Seasonal information is based on general Nigerian growing seasons and is meant as a guide.
7. The visitor counter is simulated in the browser as the brief describes, not a real analytics count.
8. Map features use the browser location only after the visitor allows it. If permission is denied the site still works fully. Maps are embedded from Google Maps and need an internet connection to display.
9. Market and produce photos were generated with AI tools and are illustrations of the sample data. Team photos are real.
